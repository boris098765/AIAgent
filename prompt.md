# Функции
* Локальная LLM
* Векторная БД
* Математический сопроцессор
* Визуализация данных (агент)
* Выполнение shell-команд
* Работа с файловой структурой
* Создание файлов
* Выполнение скриптов
* База скриптов

Структура проекта

config.py
main.py
/core
/core/db
/core/llm
/core/utils

config.py
```python
MODEL_NAME = "ministral-3:8b"
KEEP_ALIVE = "12h"
```

- /core/db содержит файлы для работы с Postgresql и pgvector.
- /core/llm содержит функции для работы с ollama, а также класс Conversation, который является агрегатором истории диалога с пользователем. Также он содержит классы Agent и Tool
- /core/utils содержит функции tools, то есть реализацию выполнения shell, python скриптов и т.д.
